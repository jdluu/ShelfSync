# Core Features

ShelfSync provides a comprehensive set of features for local network e-book library management.

## Library Management
- **Calibre Integration**: Seamlessly reads and indexes existing Calibre libraries without modifying the source metadata.
- **Metadata Support**: Displays book covers, titles, authors, series information, and tags.
- **Format Awareness**: Identifies available file formats for each title.

## Synchronization
- **Local Network Discovery**: Automatically identifies active hosts on the network using local broadcasting.
- **Pairing and Security**: Secure client authentication via a pairing PIN system.
- **Background Syncing**: Downloads book files in the background with real time progress tracking.
- **Bulk Sync**: Supports selecting and downloading multiple books in a single operation.

## User Experience
- **Unified Design**: A clean, modern interface consistent across desktop and mobile platforms.
- **Dark Mode**: Support for both light and dark themes based on system preferences.
- **Responsive Layout**: Adaptive UI that works on everything from large monitors to small mobile screens.
- **Search and Sorting**: Advanced search capabilities and multiple sorting options (Title, Author, Series).

## Progress Tracking
- **Reading Status**: Manually track progress for each book (Unread, Reading, Finished).
- **Client Side Storage**: Maintains a local record of synced content for offline access.
