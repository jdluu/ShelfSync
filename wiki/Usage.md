# Usage Instructions

ShelfSync operates in two distinct modes: Host and Client. The intended workflow involves setting up one Host device to share a library and one or more Client devices to consume and sync content.

## Host Mode Setup

To share your library from a desktop computer:
1. Select the **Host (Desktop)** role on the initial screen.
2. Click the **Select Library** button and navigate to your Calibre library root folder.
3. The application will scan the library and display a connectivity card.
4. Note the Host IP and Port, or display the QR code for easier client pairing.

## Client Mode Setup

To access a shared library from another device:
1. Select the **Client (Mobile)** role on the initial screen.
2. The application will automatically scan the local network for available hosts.
3. Select an identified Host from the list or enter the connection details manually.
4. If authentication is enabled, enter the pairing PIN displayed on the Host device.

## Library Synchronization

Once connected, you can browse the remote library:
- **Search**: Use the search bar to find books by title or author.
- **Filter**: Filter by category or reading status.
- **Sync**: Click the **Sync** button on a book card to download it to your **Offline Storage**.
- **Bulk Actions**: Use the **Selection Mode** (checkmark icon) or **Group By** filters to synchronize multiple books or entire groups simultaneously.

## Reading Management

Synchronized books appear in your **Offline Storage** (On My Device view). You can update their reading status (Unread, Reading, Finished) directly within the application to keep your progress tracked.
